# Microcredit Bank Forecasting Dashboard

A Python and Streamlit application for forecasting loan disbursements and analysing staff performance in a microcredit bank.

## Features

* Loan disbursement forecasting
* Time-series analysis
* Staff performance monitoring
* Branch performance analysis
* Loan product analysis
* Interactive visualisations

## Technologies

* Python
* Pandas
* Streamlit
* Plotly
* Statsmodels
* Openpyxl

## Installation

Install the required dependencies:

```bash
python -m pip install -r requirements.txt
```

## Run the Application

```bash
python -m streamlit run app.py
```

Upload an authorised Excel report through the application.

## Security

Do not upload confidential customer information, loan reports, or proprietary banking data to a public repository.
